# Project X

A workspace index for my experiments with visual memory and practical AI tools. This repository contains Git submodules, not a standalone application.

## Projects

- **ONE Mind / SEGMA** — a visual-memory prototype with image-sequence detection and short-term state. The source repository is private; the `one mind` submodule requires explicit access.
- **[Student Learning Feedback Assistant](https://github.com/zhuzccn-rgb/zonghesuzhipingjia)** — an early WeChat mini-program prototype. Development paused before full frontend/backend integration.

Other public projects are maintained separately:

- [AI-examiner](https://github.com/zhuzccn-rgb/AI-examiner): PDF question extraction and exam assembly workflow.
- [Folio / pdf2epub](https://github.com/zhuzccn-rgb/pdf2epub): local conversion of Manning-style technical PDFs to EPUB.

## Access

A normal clone retrieves this index. Recursive submodule checkout will require access to the private ONE Mind repository and SSH authentication. Public visitors can browse the public projects directly through the links above; this index does not grant access to private code.
